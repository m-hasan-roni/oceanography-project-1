# Project Code Repository

This repository contains two iterations of the computational model used in this academic project 1: 

1. professor_original_code_PFZ.py - The baseline framework provided by my course lecturer Dr.Subrata Sarker, Associate Professor, Department of Oceanography, Shahjalal University of Science and Technology, Sylhet-3114.
2. my_improved_code_PFZ.py - My modified, optimized version.

### My Improvements & Contributions:
* Added explicit file-path management and NetCDF4 engine selection to make local data loading more reliable and reproducible.
* Updated the workflow to use the latest January 2026 MODIS monthly datasets instead of the original dataset paths.
* Improved code organization and usability with clearer status messages and a more descriptive PFZ map title for presentation    and documentation.
