# Project Code Repository

This repository contains two iterations of the computational model used in this research project: 

1. professor_original_code_PFZ.py - The baseline framework provided by my course teacher Dr.Subrata Sarker, Associate Professor, Department of Oceanography, Shahjalal University of Science and Technology, Sylhet-3114.
2. my_improved_code_PFZ.py - My modified, optimized version.

### My Improvements & Contributions:
* Optimized the data processing pipeline to handle heavy oceanographic arrays more efficiently.
* Integrated additional visualization libraries to automate map and figure exporting.
* Corrected localized calibration constraints for our specific geographic study region.
